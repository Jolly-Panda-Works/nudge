# Security Policy

## Supported versions
Only the latest release on `main` (the `nightly` pre-release) receives fixes while the project is pre-1.0.

## Reporting a vulnerability
Please use GitHub's **private vulnerability reporting** (repository Security tab, "Report a vulnerability"). If that is not available, open an issue that says only that you have a security report, without technical details, and a maintainer will arrange a private channel.

Please include the version, platform, and steps to reproduce. **Do not include real notification content, tokens or personal data** in reports.

## Scope
Most relevant: leaking notification content (logs, backups, crash reports), insecure storage of credentials, and bypassing the Notification Access permission model.
