feat: Nudge v0.6.0 - tasks and reminders storage (M2 section 1)

- TaskItem, TaskDraft and TaskRepository with a Drift implementation:
  create (also from a notification), duplicate prevention per source
  notification, complete, reopen, archive, restore, snooze, edit, delete,
  ordered lists, counts
- a task keeps a snapshot of its source (key, package, label, whether an
  action existed) so it outlives the notification
- Drift schema version 2 with a migration adding the tasks table
- retention no longer deletes notifications that an open or done task
  points to
- AppServices exposes the task repository
- tests: draft rules, repository behavior, retention exemption
- docs: roadmap (M2 split into four sections), architecture, privacy,
  changelog; STATUS.md added to the project and updated
