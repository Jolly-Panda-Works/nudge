feat: Nudge v0.8.1 - application id com.jollypanda.nudge and release signing

- Android application id is now com.jollypanda.nudge; wire_capture.py
  sets it in build.gradle.kts (also on an already generated project) and
  CI generates new projects with --org com.jollypanda
- release signing from repository secrets (NUDGE_KEYSTORE_BASE64,
  NUDGE_KEYSTORE_PASSWORD, NUDGE_KEY_ALIAS, optional NUDGE_KEY_PASSWORD);
  falls back to the debug key when they are missing; release notes and
  the build summary say which one was used
- tools/make_keystore.sh creates the key and prints the secrets
- .gitignore excludes keystores
- docs: changelog, releasing, status

The old app.nudge.nudge install stays beside the new app; data is not
moved. Not compiled or run: CI first.
