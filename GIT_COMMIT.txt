ci: Nudge v0.5.1 - builds for every branch and tagged releases

- CI runs on pushes to every branch; outputs are artifacts named
  Nudge_v<version>_<branch>-<commit>_... (14 days, main 30 days)
- main still publishes the rolling "nightly" pre-release
- pushing a tag v<version> publishes a permanent release with the APK,
  Windows zip, SHA256SUMS.txt and the CHANGELOG section as notes; fails if
  the tag does not match pubspec.yaml; attaches files to a release that was
  drafted in the GitHub UI; 0.x versions are pre-releases
- same-repo pull requests are no longer built twice
- docs: RELEASING.md, README download table, DEVELOPMENT, CONTRIBUTING

Milestone: infrastructure
